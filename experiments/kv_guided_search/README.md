# KV 引导搜索：小型验证实验

2026-10-16。本实验验证：先查询 200 个候选的深层 KV，再用这些观测指导下一批查询，是否优于随机继续查询或语言概率排序。

## 条件与方法

- 复用 [TinyStories 小实验](../kv_inverse_tiny/README.md) 的冻结预训练模型，revision `77f1b168e219585646439073245fe87e56b3023e`。未加载之前的反演器 checkpoint。
- 候选集扩大到 **2048** 个模型已有的、以空格开头的 ASCII 英文/数字 Token 片段；从 32,751 个符合筛选条件的 Token 中选择。完整模型词表仍是 50,257。每次复核独立抽取候选集。
- 只观察第 **4、8 层**目标 K+V，128 维 float32。模型 embedding 为 64 维。没有使用目标首层 KV。
- 恢复的是**一个未知 Token**。正确前缀已知，选择 8 个固定英文前缀；不是整串未知输入或密码恢复。
- `uniform_target`：目标从 2048 候选中均匀采样，检验不服从模型概率先验的情况。它不是实际随机字符密码的 tokenizer 分布。
- `model_probability_target`：目标按模型在正确前缀下的候选条件概率采样，检验语言先验有利的情况。它也不是自然语言语料集。
- 各方法共享完全相同的最初 **200 个随机候选及其实测 KV**，初始候选选择不使用目标 ID；以后每批最多查询 20 个，预算为 220、240、300、400、600。
- KV 查询真正执行本地模型前向，仅计算请求的候选，没有提前计算全词表 KV 表。prefix cache 可复用，模型只运行到被观察层。目标 KV 的生成模拟已泄漏观测，不计入攻击查询数。
- 固定预算比较，不提前停止。目标 ID 仅用于创建模拟观测和结果评分，不传入候选选择函数。最终答案由已经查询候选的**真实 KV 距离最小值**决定。

| 方法 | 下一批候选怎么选 |
| --- | --- |
| Random | 从未查询候选中随机选择 |
| Language probability | 按原模型在已知正确前缀下的下一 Token 概率排序 |
| KV surrogate | 仅用已查询的 embedding/KV 对拟合岭回归代理，预测未查询候选的 KV，按与目标的预测距离排序 |
| Shuffled embedding control | 相同代理，但故意打乱 Token 与 embedding 的对应关系，检验几何关系是否提供帮助 |

代理学习 `embedding → 深层 K+V`，带截距，ridge=0.01。每批查询后用所有已观测点重新拟合。归一化统计也仅来自已查询点。评分扫描全部未查询 embedding，但**不对这些候选执行原模型前向**。

**这轮用闭式岭回归实现连续代理，不是对原模型求梯度，也不是逐样本 embedding 梯度下降。** 它验证的是“少量 KV 观测能否指导搜索”这一核心假设。

## 如何解释

**均匀目标支持方向性假设。** 复核中共同的 200 次初始查询已经找到 1/32。再查询 20 个后，第 4 层 KV 引导达到 28/32，第 8 层达到 25/32；随机为 1/32，语言概率为 2/32。也就是说，在初始没找到的 31 个目标中，KV 引导新恢复了 27 个和 24 个，而随机是 0 个，概率是 1 个。

在初始未命中目标上，指标文件还报告真实 KV 最佳距离相对初始最优值的改善。首轮 @220：第 4 层 KV 引导平均改善 94.42%，第 8 层 83.94%；随机分别约 0.86%、0.17%。独立复核指标见 JSON。

**语言先验有利时，KV 引导并不总占优。** 复核的概率采样目标在第 8 层 @220，语言概率恢复 30/32，KV 引导仅 16/32；@600 两者均为 32/32。第 4 层 @600，概率为 32/32，KV 引导仍为 31/32。

首轮的均匀目标 @220 结果为第 4 层 15/16、第 8 层 13/16；随机和概率均 1/16，方向与复核一致。

打乱 embedding 对照没有同等级提升，支持代理使用了 embedding 与深层 KV 的对应关系，而不是仅靠相同查询数量。有限样本、共享前缀和特定模型仍限制结论。

## 重要边界

- 这是受控的**共享初始 200 次查询后的继续搜索**。语言概率基线也被迫先做这 200 次随机查询；独立使用概率方法通常会从一开始就按概率查询，所以本实验不是对其最佳总体策略的完整比较，也不是论文 Collision+ 原实现。
- 2048 候选中的 200 点约占 9.8%，不等于在几十万词表上只观察 200 点。
- 小模型 embedding 只有 64 维，200 个观测点超过代理的 65 个输入项（含截距）。大模型维度高于 200 时，同样的拟合可能欠定；不能据此保证仍可估计可靠方向。
- 本实验利用已知模型 embedding，属于白盒条件。前缀正确且已知，目标是单个 Token；未知前缀的误差传播尚未测试。
- KV 完整、float32、布局和位置已知，无量化误差、损坏、缺失或窗口淘汰。
- 岭回归是线性近似，深层映射不保证全局线性，也有一个第 4 层目标在 600 次内仍未恢复。
- 候选打分仍扫描词表，减少的是昂贵的原模型查询，不是消除了所有随词表大小增长的计算。
- 主要比较查询预算。报告中的 fit/rank 和 forward 时间不包含下载、加载、共同前缀、初始 200 次共享成本或目标生成；不能直接作为端到端加速倍数。
- 未加入主动探索/不确定性估计；当前 KV 代理每轮纯选预测最接近的点。后续可以验证探索是否减少失败。

## 文件与复现

- [`search.py`](search.py)：候选集、实时查询 oracle、四种搜索、预算曲线和指标。
- [`validate.py`](validate.py)：独立检查保存轨迹：共享初始观测、无重复查询、预算、数值有效、真实距离选择与正确 ID 一致。
- [`results/metrics.json`](results/metrics.json)：首轮指标；[`results/trials.json`](results/trials.json)：逐目标查询轨迹。
- [`replication/metrics.json`](replication/metrics.json)：独立复核指标；[`replication/trials.json`](replication/trials.json)：复核轨迹。
- 两个输出目录均保存 `candidates.json`，包含完整的 2048 候选 ID/文本。
- [`run.log`](run.log)、[`replication.log`](replication.log)：运行日志。

复用相邻实验的 Python 环境与已下载模型，在工作区根目录执行：

```sh
kvidence/experiments/kv_inverse_tiny/.venv/bin/python \
  kvidence/experiments/kv_guided_search/search.py

kvidence/experiments/kv_inverse_tiny/.venv/bin/python \
  kvidence/experiments/kv_guided_search/search.py \
  --seed 20261018 --trials-per-scenario 32 \
  --output kvidence/experiments/kv_guided_search/replication

kvidence/experiments/kv_inverse_tiny/.venv/bin/python \
  kvidence/experiments/kv_guided_search/validate.py
```

如需保留结果，使用新的 `--output` 目录。首轮约 7.08 秒，复核约 14.31 秒，CPU 4 threads，macOS ARM64。不同机器时长会变化。

模型下载与环境安装见相邻 [README](../kv_inverse_tiny/README.md)。本实验没有更改 LiteRT-LM、APK 或原有取证数据。
