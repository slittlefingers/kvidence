# KV 数值一致性验收：逐维最大误差

按本次讨论，将“距离必须缩小到几个 LSB，否则不允许接受”作为后续取证验收条件。暂按此前讨论的 4 LSB 实施标准记录；这是目标阈值，不是本轮实验已经证明安全的阈值。

## INT8 KV 的条件

必须获得实际 KV 的整数编码、scale、zero-point（或等效 affine 参数）、分组方式和位置/通道布局。观测与候选必须在同一量化网格上比较，不能直接比较两个各自使用不同 scale 的整数编码。

$$
E_{\max}=\max_{t,h,d,\,b\in\{K,V\}}
\left|q^{\mathrm{candidate}}_{b,t,h,d}-q^{\mathrm{observed}}_{b,t,h,d}\right|.
$$

- 只有 E_max <= 4 才通过本项数值验收；任何一个坐标超过 4 都不通过。
- 缺少量化网格、位置不明、格式不一致或数值非有限时，状态为无法验收，accepted=false。
- NMSE、平均绝对误差、cosine、两个候选谁更近、生成内容相似，都不能代替本项检查。
- 整段验收须覆盖全部要求验证的位置，不能只报告平均值或少数较好位置。逐 token 严格恢复时，某一步未通过就不能将该 token 作为已确认前缀继续认证；研究中的推测分支可以保留，但必须标为未确认。
- 若当前候选未通过，应继续搜索或改善前缀/媒体表示，不能为了输出答案而放宽阈值。

通过误差阈值表示“数值相容的候选”，本身不证明候选唯一；多个候选同时通过时须保留歧义。

## 本轮结果的状态

本轮模型权重是 W8，但实际观测 KV 是 BF16。BF16 的 ULP 随数值大小变化，不能直接当作 INT8 固定量化网格的 LSB；NMSE 也无法直接换算成几个 LSB。本轮没有采集 INT8 KV 的编码与量化参数，因此 **尚不能执行 INT8 的 4 LSB 验收，accepted=false**，而不是已测出一个超过阈值的 INT8 误差。

原有图片反演、搜索轨迹和原文对照结果均保留。39/39 token ID 与真值相同是独立的实验事实，但不等于通过本标准。本次只补充验收定义及当前结果状态，没有修改原搜索算法，也没有声称已将误差降到 4 LSB。

下一步需要在实际目标 KV 格式下重放，报告逐位置最大 LSB 差、超限坐标数和最差坐标；同时单独测量正确原始前缀下的执行路径尾差。若目标仍采用 BF16，则必须另行规定 BF16 ULP 或数值误差标准，不能沿用 INT8 LSB 的名称。
