# KVidence：局部排除、完整集合恢复与可信停止研究

本轮承接 [统一误差界诊断](../kv_exclusion_diagnostic_05b/RESULTS.md)。原搜索、模型、数据及已有结果全部冻结。本目录记录当前研究的完整实验、证明和结论；不把“研究完成”理解成必须得到一个正面加速定理。

## 在本轮局部实验运行前固定的方案

### A. 完整答案辅助的局部界诊断

- 复用原 64 个目标/层案例、原线性和线性 + RBF 两种代理的独立查询轨迹。
- 模型 Qwen2.5-0.5B；FP32 KV；固定正确短前缀；有限候选集大小 10,000；第 12/24 层。
- 拟合预算 200/400/600；阈值沿用归一化最大坐标距离 ε=0.10/0.25。
- 分组 1/8/32/128 组。两类分组：按预测距离排序后递归均分；按已保存 PCA32 embedding 特征、每个节点选最大方差维度并按中位数递归均分。分组不用未查询真实 KV。
- 同时检查对称误差界和仅用于排除的单侧误差界。主局部设置为 32 个预测距离分组，其余为预设敏感性分析，全部报告。
- 完整表仅在预测和分组完成之后，计算各组的真实最大残差。它不是实际算法可免费获得的界。
- 记录排除量、剩余补查量、错误排除、所有匹配候选是否已查询。只验证有限表，不宣称模型参数证书。

### B. 不读取完整答案的经验局部界

- 固定预算 600 时的代理，不再拟合，避免校准标签反向进入训练。
- 从 9,400 个未查询候选中均匀无放回抽取 200/600/1,200 个额外校准样本，每项固定 5 个随机种子。
- 主设置：预测距离分组，32 组，600 个额外校准点。另保留全局 1 组作为基线；128 组以及 PCA32 embedding 分组仅在 A 中研究。
- 对每组以校准样本上的最大非负过预测残差作为单侧半径；无校准样本的组半径为无穷，不排除。使用系数 1，不调放大系数。
- 查询所有未被排除的剩余候选后返回已经实际验证的匹配集合；随后独立评分是否仍有真实解被排除。
- 该经验方法没有全候选覆盖保证；它是检验校准与实际漏解关系的对照。5 个重复共享模型/案例，不是独立的模型泛化证据。

### C. 有明确概率保证的随机审计与精确回退

- 对 B 所提出的排除集合 E，独立均匀无放回审计 `ceil((1-delta)*|E|)` 个候选，delta=0.05/0.01。
- 若审计发现任何匹配，查询 E 中所有剩余项；否则返回目前全部已查询匹配项。
- 此单次审计的漏解概率对任意固定残余匹配集合至多为 delta，证明见 `THEORY.md`。随机审计独立于产生 E 的拟合/校准信息；不重复尝试审计直到“通过”。
- 理论保证依赖确定性查询分类、固定目标和候选集合，不依赖代理正确。概率指单次运行的审计随机性，不等于所有实验同时以同一 delta 正确。
- delta=0 的精确回退查询全部 E：必然找全，但总预算为 10,000。不能称为新加速算法。
- 实验通过计数 oracle 回放现有模型表，计入搜索、额外校准、补查、审计和回退；不将回放时间解释成在线推理耗时。

## 理论交付

1. 有效下界 + 剩余候选实际查询的完备性证明。
2. 局部单侧残差上界及基于模型/残差 Lipschitz 常数的条件性构造；明确哪些参数界未在真实模型上取得。
3. 不限制未查询标签的黑盒情形下，零漏解保证的查询障碍，以及只返回验证匹配时随机算法的期望查询下界。
4. 有限总体随机审计的精确漏检概率、最坏情形和停止规则。
5. 阈值内相容集合与唯一恢复的区别、单 token 保证与整段前缀未知恢复的区别。

不把量化误差 ±4 LSB 与代理误差混同，不把 FP32 阈值换算成 INT8；不宣称未运行的 Gemma/NPU、未知前缀、全词表或长上下文实验结果。

- `experiment.py`：局部界与计数 oracle 的端到端回放。
- `validate.py`：独立结果复算、解析反例、有限总体审计枚举测试。
- `THEORY.md`：完整证明、假设和适用范围。
- `REPORT.md`：研究结论、全部主要实验与局限。
- `results/`：原始数据、摘要、输入哈希和审计记录。
