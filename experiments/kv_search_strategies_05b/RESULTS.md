# 0.5B 独立搜索策略对比

实验日期：2026-10-18。原方法保持不变；本报告由 `report.py` 自动汇总全部冻结策略。

完整设置与方法定义见 [README.md](README.md)。本轮研究相同查询预算下的搜索效果，不提供找全证书。

## 设置

- Qwen2.5-0.5B，FP32 模型计算与 KV，10,000 个英文/数字候选，固定正确前缀，恢复一个未知 token。
- 开发组为上轮 16 个目标；确认组另取 16 个目标，目标 ID 与开发组不重叠。两组共享候选池和四个前缀。
- 两层分别比较，同一目标会在两层重复出现；不能按层数扩充独立样本量。
- 所有方法共享初始 200 次查询，每批 20 次，最多 600 次。首要指标预先固定为命中 @220。
- 本轮新策略使用完整 896 维 embedding 和全部已查询训练样本，没有未证明的永久候选排除。
- 全候选 KV 表只作为隐藏 oracle 和独立评分依据，搜索函数看不到目标 ID 或未查询 KV。
- 本实验未对确认组调参；并列报告各方法，不把探索性胜出解释为普遍最优。

## 新目标上的主要观察

第 12 层原方法 @220 为 5/16，@600 为 15/16。

- 原拟合 + 最大坐标距离排序：@220 2/16，相差 -3 个；@600 11/16；搜索计算开销约为原方法 1.04 倍。
- 目标附近加权拟合：@220 5/16，相差 +0 个；@600 15/16；搜索计算开销约为原方法 1.01 倍。
- 线性 + RBF 非线性代理：@220 6/16，相差 +1 个；@600 15/16；搜索计算开销约为原方法 2.53 倍。
- 16 个近邻 + 4 个信息采集：@220 5/16，相差 +0 个；@600 15/16；搜索计算开销约为原方法 1.38 倍。

第 24 层原方法 @220 为 15/16，@600 为 16/16。

- 原拟合 + 最大坐标距离排序：@220 5/16，相差 -10 个；@600 16/16；搜索计算开销约为原方法 1.05 倍。
- 目标附近加权拟合：@220 15/16，相差 +0 个；@600 16/16；搜索计算开销约为原方法 1.01 倍。
- 线性 + RBF 非线性代理：@220 14/16，相差 -1 个；@600 16/16；搜索计算开销约为原方法 2.59 倍。
- 16 个近邻 + 4 个信息采集：@220 15/16，相差 +0 个；@600 16/16；搜索计算开销约为原方法 1.41 倍。

**本轮没有新策略在两层都保持 @220 命中不下降、并至少一层提升。** 非线性代理在第 12 层出现较早命中的信号，第 24 层未复现这种优势。原方法保留为基线。

这些是本轮的配对结果。16 个新目标仍属小样本，而且有四个预先固定的新策略；个别方法在某层胜出，尚不足以认定它在其他目标、前缀、模型上都更好。
若继续，应固定有希望的策略再扩大新目标验证，并增加在线真实模型前向计时；原方法仍保留不变。

固定选择确认组第一个候选池的前四个目标、两层，每种方法测一次。CPU 四线程，真正逐批运行原模型，方法顺序按案例随机打乱。以下包含初始查询、后续前向、拟合和选点，不包含模型加载、前缀缓存准备和预热。

**首次命中时间由事后目标 ID 标注，不等于算法自行判断成功或找全的停止时间。** 固定 600 次耗时用于比较同预算运行成本；首次命中时间用于观察搜索轨迹。
