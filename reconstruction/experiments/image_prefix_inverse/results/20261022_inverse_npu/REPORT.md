# 逆向模型候选的真实 NPU 回放与搜索

日期：2026-10-22。使用实验 Release `v2026.10.22-experiments` 的种子 20261022 检查点。
实验归档 SHA-256：`e2462e7679654acc6ae0e372edf7371011d5a0546c2a141c65785b2f1de295ee`；
下载后核对了归档及选用检查点的哈希。逆向模型不重新训练。

结论：K+V 岭回归的预测可作为有效搜索起点。在三个预先确定的位置，同样候选查询预算下，
学习初始化显著降低实际 KV 误差；此次尚未达到 RMSE < 0.125 LSB 的验收条件。

## 协议

- 真正的 Pixel 10 Gemma 4 E2B NPU decoder，手机 CPU adapter；layer 5 INT8 K+V。
- 使用图片级独立测试集的 `test_007`，包含 8 张未参加训练的图片。
- 观测 20 个原采集 prefill 分块起始位置，绝对位置 133–1976。
- 用真值前缀按原始分块重放，全部图片位置的 KV 与存档逐位一致。
- 真值 embedding 仅用于前缀和明确标注的控制项，不进入当前候选预测或搜索。
- 模型只接收当前 KV；最后一步前缀网络另接收严格早于当前位置的真值 embedding。
- 从真实 `.litertlm` 读取公开 adapter 的 1536×768 投影矩阵，用左逆将预测转为 768 维，
  RMS 归一化后再通过手机真实 adapter，作为受 adapter 约束的搜索输入。
- 搜索位置在 NPU 测量之前固定为 133、1055、1976，不按结果挑选。

该测试没有使用实际恢复前缀；不是完整图片连续恢复验证。
昨天的约 5.51 LSB 属于训练图片 0001 的不同位置，不能用来声称此次获得某个搜索加速倍数。

## 预测 embedding 直接回放

以下为 20 个位置各自 RMSE 的算术平均，单位 LSB，不是 embedding 的浮点 RMSE。

| 候选 | 平均 KV RMSE | 中位 KV RMSE |
|---|---:|---:|
| 原始真值 embedding 控制 | 0 | 0 |
| K+V 岭回归预测，直接输入 | 13.8354 | 12.9520 |
| 最后一步前缀网络预测，直接输入 | 13.8770 | 12.9792 |
| K+V 岭回归预测，经真实 adapter 投影 | 13.8286 | 12.9195 |
| 训练集均值 embedding | 51.9830 | 51.2647 |
| 上一个位置的真值 embedding | 47.2804 | 48.0344 |

岭回归直接预测的最大误差为位置 1836 的 33.1747 LSB，不能假设每个位置都接近均值。
此次最后一步前缀网络未显示优于岭回归的 NPU 误差。两个网络方案不能与旧的浮点 embedding
RMSE=0.3066 混为同一个单位。

## 相同查询预算的搜索对照

两路各评估 64 个初始化候选，再做 4 轮完整 768 方向的中心差分与阻尼更新，
每轮 1536 个探针 + 36 个更新候选。每路总计 **6,352 次实际候选查询**。

学习初始化池包括岭回归投影向量及其 63 个局部扰动；随机池为 64 个单位 RMS 高斯向量。
两路使用相同方向、初始探针 RMS 0.0871384、阻尼和步长因子；无改善时放大探针半径，
最多 4 倍。只保留实际 NPU 测量更好的候选。学习池构造与随机池分布不同，
这里比较的是整套初始化方案，不单独归因于某一个候选。

| 位置 | 图片 | 学习池初始最优 | 学习池 + 4 轮 | 随机池初始最优 | 随机池 + 4 轮 |
|---|---|---:|---:|---:|---:|
| 133 | 0069 | 14.2032 | **5.2572** | 56.4919 | 35.3949 |
| 1055 | 0032 | 11.7597 | **5.5068** | 42.9587 | 17.7801 |
| 1976 | 0090 | 12.4869 | **5.0101** | 58.7685 | 16.4298 |

每路测量与优化约 12.8–13.7 秒，不含模型下载、检查点加载和手机模型初始化。
总在线实验阶段约 99.38 秒。随机对照没有做单独超参数调优，也没有多尺度搜索；
因此这不能代替与历史最强搜索方案的完整对比，更不能断言已到平台。

## 长前缀数值敏感性复核

位置 1976 出现一个独立于预测模型的现象：

- 原始真值 embedding 输入：0 LSB。
- 原始真实 pre-adapter 特征经过手机 adapter 后，与存档 embedding 逐位相同：0 LSB。
- 真值 embedding 经公开矩阵左逆、归一化、再通过手机 adapter，embedding 的 RMSE
  仅 `2.8134e-7`、最大逐维差 `1.1921e-6`，但 KV RMSE 为 **4.9110 LSB**。
- 固定相同前缀，在新 worker 中重复两次，上述结果完全重复。
- 精确真值与直接/投影候选混批，结果仍为 0；近似投影真值单独或混批，均为 4.9110。
  在这些控制中未发现批次组成改变评分。
- 此位置搜索所得最佳向量单独重测为 **5.0101 LSB**，与搜索时结果相同。

这说明该位置对微小数值变化有显著敏感性，不能只根据 embedding 接近就推断 KV 接近。
具体机制未定位，不能直接称为普遍的数值误差下限；原始特征本身确实能实现 0。
因此，5 LSB 附近的残差还需结合数值稳定性研究，不能全部解释为模型没有学准。

## 文件与边界

- `protocol.json`：预先固定的位置、预算、模型哈希和源代码哈希。
- `forward_results.json` / `forward_metrics.csv`：所有位置的 LSB、分 K/V 和反量化误差。
- `search_*.json`：完整曲线与预算；同名 NPZ 保存最佳 768 维输入及实测 KV。
- `batch_projection_audit.json`、`projection_audit.json`：两次独立数值控制。
- `summary.json`、`checks.json`：汇总与一致性检查。
- `source/`：此次测试代码快照；`device/` 等目录记录真实设备模型与运行时哈希。

当前证据支持在真值前缀条件下用学习候选减少有限预算搜索的误差。
尚未验证预测前缀的误差累积、所有 token 位置、其他独立上下文或达到 0.125 LSB。
此次结果仅保存本地，没有自动推送至公开仓库。
