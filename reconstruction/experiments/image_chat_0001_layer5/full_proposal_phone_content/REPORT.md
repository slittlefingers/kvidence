# 图片内容对照：真实手机 adapter 与 NPU

这一个样本的**粗粒度场景与原图吻合**：第二组完整候选让手机模型描述出
多人在草地上踢足球，并提到足球、运动服、树木。第一组仅描述为多人在
草地上进行体育活动。但两组都没有通过逐图片位置的原始 KV L2 < 5。

## 候选来源与评价顺序

这里检查的是此前 `fit/seed_17/latent.npy` 和 `fit/seed_29/latent.npy`
保存的完整 260-position pre-adapter 候选。它们由先前的 **MLX 代理模型**
优化得到；该代理与手机模型不数值等价。这不是本次手机 SPSA 已经恢复
整张图片的结果，也不能据此将该代理称为经过验证的手机等价模型。

本次重新将两个候选输入**手机 `.litertlm` 内的 CPU vision adapter**，
再通过真实 NPU decoder 重放，记录第 5 层 KV。此处没有直接使用先前
电脑 adapter 输出的 `features.npy`。手机前缀由候选前向计算产生，没有
导入目标 KV，也没有输入原图或原始用户文本。

每组使用同一个事先固定的问题：

> Describe the image briefly. Name the main visible objects and actions. Answer in English.

两组描述生成并保存后，独立评价步骤才打开原图和 COCO 注释。恢复程序
启用了私有数据读取保护。两组均正常结束，没有触及 256-token 输出上限。

## KV 验收与语义评价是两项结果

| 完整候选 | 各位置 L2 的平均值 | 最大 L2 | L2 < 5 的位置数 |
|---|---:|---:|---:|
| seed 17 | 21.86354 | 29.97278 | 0 / 260 |
| seed 29 | 21.66237 | 29.10594 | 0 / 260 |

距离是原始数值空间中每个位置拼接 K、V 后的 L2；不是 LSB，也不是
逐维平均误差。因此结论是：**这一实例中，未达到 KV 阈值的候选仍能
产生与原图一致的粗粒度语义描述**。不能将其写成通过 `< 5` 的图像恢复。

这只是一个样本、两组初始化的定性对照，没有随机表示负对照或多图
盲评，不能据此估计恢复准确率、证明表示唯一性或排除模型先验的影响。
本实验也没有生成恢复后的像素图。
