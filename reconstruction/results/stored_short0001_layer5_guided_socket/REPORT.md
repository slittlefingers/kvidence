# 持久连接优化：第 5 层、109-token 密文恢复

同一数据库样本 `0001`、同一 Gemma 4 E2B Tensor G5 模型、同一第 5 层 KV，guided 在线恢复从 **610.764 秒降到 222.327 秒**，本次观测约 **2.75 倍**加速。独立评估为 **109/109 token 正确**。新旧实验都完整查询 16,530 个候选、执行 388 次物理候选调用；逐位置查询序列、选中 ID、接受的 KV 字节和距离均一致。

## 改动与不变条件

主机/手机逐次 ADB 文件交互替换为一个持久 socket，经 ADB 端口转发承载。手机稳定排序 logits 后返回完整原始 token ID 排名；CPA 开批指令合并进首次物理查询。搜索代码、阈值与模型参数未修改，未裁剪词表、提前终止或减少候选。

guided 仍为模型概率 50 + 随机 150 个初始种子、每轮 ridge 提议 20 个；完整词表 262144、seed=20261019、逻辑 batch=256、物理槽位 128，接受条件为拼接 K+V 原始数值 **L2 < 4**。目标是已有 APK 生成回复后保存的 KV，其中待恢复范围为密文 payload 对应的 109 个位置；已知公开前缀 11 个 token。恢复只用自己的前缀，不加载目标真实前缀 KV。

| 正确 token | 109/109 | 109/109 |
| 候选查询数 | 16,530 | 16,530 |
| 物理候选调用数 | 388 | 388 |
| 接受候选与提交后距离 | 全部 0 | 全部 0 |
| 在线总时间 | 610.764 s | 222.327 s |
| 主模型调用时间 | 33.160 s | 29.554 s |

新旧输出的 156-byte 密文字符串完全一致；这里恢复的是密文表示，不是解密出原始 LMSYS 明文。独立正确性记录见 [evaluation.json](evaluation.json)，机器可读比较与逐项一致性检查见 [transport_comparison.json](transport_comparison.json)。

## 时间主要节省在哪里

在线 RPC 的主机总耗时由 578.589 秒变为 192.781 秒；相应手机 worker 内部耗时由 212.322 秒变为 185.212 秒。两者差额从 **366.267 秒降到 7.569 秒**。这个差额包含主机协议处理、进程调度、ADB 往返和传输等，不能称为纯网络传输时间。

新结果中，手机候选查询内部仍用了 151.196 秒，其中主模型调用约 23.211 秒。剩余包括 embedding/PLE、RoPE/mask、输入拼装、张量读写等，尚未进一步拆分。因此模型主计算很短的观察成立，但消除通信后也不能直接以 29.554 秒估算完整恢复时间。

当前排名仍为完整词表的 int32 ID，每位置 1 MiB，109 个位置仍传 109 MiB；候选 KV 共 16.143 MiB，提交 KV 0.106 MiB。传输字节数没有缩小，收益主要来自取消逐条 shell/文件操作。后续如要减少排名流量，需要单独设计按需排名接口并验证候选顺序不变。

## 验证范围与局限

- 47 项主机测试通过；新增测试覆盖分片收包、截断、非法长度/序号、RPC 错误、断开后禁止重发以及合并开批指令。
- 同一个新版 APK 的 file/socket 设备检查通过：完整排名、候选 KV、第二个物理批候选的保留提交、提交后的下一位置 KV 均一致。记录见 [设备通信验证](../transport_validation_20261019/validation.json)。
- 完整样本对照使用先前一次旧实现运行和本次一次新实现运行，没有随机交错重复或热状态控制。2.75 倍是本样本的观测值，不能推广为所有模型/输入的固定加速；手机 worker 与主模型耗时也存在运行间变化。
- 本报告完整重跑了 guided；CPA 的新连接另外做有限集成验证，没有重新运行这条密文的完整 109-token CPA 基线，不能直接更新两种攻击方法的端到端加速比。
- 新测试 APK 改变了哈希，旧 CPA 校准资产未覆盖或修改。在新 APK 下重新采集了独立已知文本的 8 位置 × 1024 候选 pilot：阈值与旧 pilot 相同，见 [新校准资产](../../assets/cpa_gemma4_pilot_socket/calibration.json)。它仍不是全文、全词表正式校准。

在线时间不含模型初始化、资产加载、已知前缀预填；`decoder_seconds` 是主 decoder/prefill 运行调用的墙钟时间，包含运行时/驱动开销，不能当作纯 NPU kernel 时间。测试 APK 已编译并安装，正常退出时 worker 关闭、ADB 转发移除。
