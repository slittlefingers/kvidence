# Gemma 4 KV8：数值状态误差沿 token 序列的传播

日期：2026-10-17（Australia/Melbourne）。本实验研究历史缓存数值变化是否影响后续新生成的 KV，并检查指定位置的真实候选匹配。模型和 tokenizer 不变，沿用固定 W8 Gemma 4 E2B 与真实运行时 KV8。

## 1. 这次与之前的 ±4 LSB 证书有什么区别

之前的实验固定全部候选和观测向量，只改变最后比较的整数码。本次真正把扰动写入历史缓存，再继续执行后续 token 的 attention、FFN 和量化。因此后续新 KV 的变化已经包含模型传播影响。

所有轨迹始终强制输入同一条真实 token 序列，不将任何匹配结果作为下一步输入。这样可以隔离数值状态传播与错误 token 传播。本实验不是未知输入的自由运行恢复，也没有评估代理搜索是否能命中目标。

## 2. 设置

| 项目 | 设置 |
|---|---|
| 模型 | Gemma 4 E2B IT MLX 8bit，固定 revision `03dcf209f3f549b4075e7191e77cf69b3d48e1b2` |
| 权重 / 缓存 | W8 affine；所有 15 个实际 KV 生产层采用 KV8，group_size=64 |
| 硬件 | Apple MLX GPU；不是 Pixel NPU |
| 输入 | 一段英文、一段空格分隔随机字母数字，各 128 token，包含 BOS |
| 原始观测 | 一次完整 128-token causal prefill，读取其 KV |
| 对照 | 完全无外加扰动的逐 token decode |
| 一次扰动 | 第 16 个 token 处理后，各 KV 生产层该位置 K/V 码各加 seeded random ±4，裁剪到 `[0,255]` |
| 持续扰动 | 从第 16 个 token 开始，每处理一个 token 后，对所有生产层新写入位置各加 ±2 或 ±4 |
| 保持不变 | token ID、scale/bias、offset、其余已写入位置以及权重 |
| 观察层 | 第 10、15 层实际独立 KV 生产层，每位置 K+V 为 1,024 维 |

每个持续扰动轨迹共注入 113 次。±2/±4 的符号按相同输入、位置、层和 K/V 配对生成，但这只是一个固定随机种子，不是最坏方向攻击或跨种子统计。

注入发生在当前 token 完整计算结束之后。后续误差指标读取新 token 的 KV **在本步注入之前**的值，所以报告的新 KV 偏差不是直接把本步的 ±2/±4 重新当作传播效果。

## 3. 新 KV 的数值变化

下表是第 15 层新 KV 相对同序列无扰动 decode 的 L2 偏差比例，按位置区间取平均。分母是各位置无扰动新 KV 的 L2 范数。第 1–16 个位置的新增偏差为 0。

| 输入 | 扰动方式 | 17–32 | 33–64 | 65–96 | 97–128 |
|---|---|---:|---:|---:|---:|
| 英文 | 仅一次 ±4 | 4.05% | 2.99% | 3.91% | 6.10% |
| 英文 | 每步 ±2 | 4.52% | 5.94% | 9.74% | 12.55% |
| 英文 | 每步 ±4 | 7.80% | 10.00% | 15.32% | 22.19% |
| 随机字母数字 | 仅一次 ±4 | 2.47% | 2.40% | 2.36% | 4.89% |
| 随机字母数字 | 每步 ±2 | 3.46% | 4.62% | 4.21% | 4.83% |
| 随机字母数字 | 每步 ±4 | 6.08% | 8.22% | 7.16% | 8.80% |

这说明在本次强制正确 token 的条件下，历史缓存扰动确实会影响后续新 KV；持续扰动在英文样本中出现明显更大的后段偏差。随机样本不呈单调增长，一次扰动也没有逐步线性增加的固定规律。

完整 prefill 与无扰动逐 token decode 本身也不逐位相同：第 15 层平均相对 L2 偏差，英文前 16 个位置约 2.27%，后 32 个位置约 6.47%；随机样本分别约 2.13%、4.94%。这些差异混合了计算路径与其历史状态变化，不能全归因于外加扰动。

一次扰动有时会使某位置更接近完整 prefill 参考，说明新增偏差可以部分抵消原执行路径偏差。不能将所有扰动直接看成同方向累加。

### 3.1 LSB 的解释

后续模型重新计算的新 KV 会产生新的 scale/bias。因此后续整数码差不能再直接解释为相同物理单位下的 LSB 差。

保存的 `new_kv_rms_in_reference_step_units` 用实际反量化值差除以该维参考量化步长，表示参考尺度下的等效步长偏差；它不是两份量化码直接相减。英文持续 ±4 轨迹，第 15 层该指标从 17–32 的平均约 4.63 增至 97–128 的约 11.45。这个数字进一步说明“每步注入至多 4 个码”不代表“后续所有新 KV 与参考都最多相差 4 个码”。

同时记录完整历史缓存的 L2 与 RMSE；不能仅因为缓存长度增长使总 L2 上升，就认定单位置误差被放大。上表使用新位置的误差，避免这种规模混淆。

## 4. 预先指定检查点的真实匹配

英文检查第 33、64、128 个位置，目标分别为 ` window`、` garden`、`2`；随机样本检查第 33、65、128 个位置。位置包含 BOS，实际 ID 和文本见 [metadata.json](metadata.json)。

每个检查点先保存攻击者当前的真实偏移状态，再让每个候选从这份状态出发做前向，而不是使用原始正确数值状态。目标始终是完整 prefill 的原始 KV。

- 前两个检查点使用同一组 10,000 个字母数字候选，明确包含检查点目标。
- 最后一个检查点使用完整 86,512 个严格字母数字候选。
- 两段输入 × 四个轨迹 × 三个检查点 × 两个观察层，共 48 个匹配案例，**48/48 均选对**；其中完整候选集的匹配为 16 个。
- 全部预先指定案例的最小经验距离差（最近错误距离减正确距离）约为 8.768，使用 raw affine 值的 L2 单位。

这些检查点只能说明观察到的数值偏差在所选位置尚未改变最近邻。它们不是每个位置都进行的恢复，也不能代表整串成功率。尤其是最后的数字目标可能有较大的分离间隔，不能因最后一个位置选对就推出中间位置全对。

## 5. 偏差最大位置的事后诊断

为避免预先选定位置漏掉异常，另选择每段持续 ±4 轨迹中“第 15 层新增 KV 相对无扰动 decode 偏差最大”的位置。分别重放 clean 和 repeat4，逐位置核对量化码和元数据与原轨迹一致，再做完整候选匹配。

英文所选位置为第 127 个 token `7`，相对无扰动的偏差约 116.83%；随机样本所选位置为第 108 个 token（空格），约 46.10%。这里“116.83%”是两个向量差的范数相对基准向量范数，不是错误 token 的概率。

空格不属于之前的严格字母数字候选规则，因此诊断候选集为 86,512 个严格候选加空格，共 86,513 个，确保真 token 没有被过滤掉。诊断结果保存在 [diagnostics/results.json](diagnostics/results.json)，需与预先指定的 48 个案例分开报告；这些位置由观测结果事后选择，不能混合成无偏准确率估计。

两段输入 × 两个轨迹 × 两个层，共 8 个事后诊断匹配，也全部选对。但第 15 层的经验距离差变化方向不同：

| 诊断位置 | 无扰动 decode | 每步 ±4 LSB | 是否仍选对 |
|---|---:|---:|---|
| 英文第 127 个 token `7` | 23.285 | 0.531 | 两者均正确 |
| 随机样本第 108 个 token（空格） | 3.640 | 16.955 | 两者均正确 |

英文的位置出现了显著余量缩小；随机样本该位置的余量反而增大。因此不能从偏差范数变大直接推出最近邻准确率降低，扰动方向以及不同候选受前缀状态影响的方式也很重要。

## 6. 怎样解释结论

可以确定：小的历史缓存码扰动可以改变后续新 KV，持续扰动的影响在本次某些输入中随位置增大；这条传播路径与是否猜错 token 无关，因为所有 token 都被强制为真实值。

不能直接推出：误差必然单调或指数累积；所有后续 token 都会误判；±4 LSB 永远安全；128 token 的结果可外推到 10,000 token、滑动窗口淘汰或 NPU。

理论上，最终仍需比较每个位置的实际总误差与候选分离间隔。前面的“最终 KV ±4 LSB 证书”不能替代这里的状态传播分析，因为注入历史缓存后，新 KV 的偏差已经可能超过原本的最终码扰动模型。

在工作区根目录运行新的实验目录：

```bash
kvidence/experiments/kv_guided_search_gemma4_int8/.venv/bin/python \
  kvidence/mathematical_analysis/sequence_error_experiment.py \
  --output kvidence/mathematical_analysis/sequence_error_results_replication
```

默认目录的未完成匹配可用 `--scan-only` 继续，已保存的结果会跳过；`--analyze-only` 仅从现有载荷与匹配结果重新生成统计。诊断脚本目前读取默认目录，输出其中的 `diagnostics/`。

所有误差率都是经验数值结果，不是区间算术认证或全模型误差上界；多个位置、层和轨迹共享输入，不能作为独立样本估计泛化概率。
