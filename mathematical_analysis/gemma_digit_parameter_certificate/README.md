# Gemma W8 参数证明：一个全前缀的局部分离结果与 FFN 处的证明缺口

日期：2026-10-17。模型：本地 Gemma 4 E2B W8，revision `03dcf209f3f549b4075e7191e77cf69b3d48e1b2`。候选：十个单 token 数字 `0`–`9`。这是数学参数认证，不是新一轮前缀采样实验。

## 1. 已证明与未证明的内容

**已证明：** 对 W8 载荷定义的精确 affine embedding 行和实数参考算子，十个数字的 45 对输入，在第一个 attention 残差相加之后、第一层 FFN 之前，均保持正距离；对全部前缀统一有效的 L2 下界至少为 **1.05756077115822**。

**未证明：** 第 10、15 层 KV 的全前缀分离；实际 BF16 算术与 KV8 缓存执行的稳健恢复；真实数值误差下的整段恢复。这个局部结果不能替代上述结论。

这里没有进行首层 KV 攻击。分析第一个 attention 残差，是为了定位整个深层证明链最早能成立、以及在哪里失去保证。

本轮读取了 embedding 与归一化参数，未运行 Transformer 前向，未选择或枚举任何具体前缀。FP64 只用于寻找一个候选证明方向；最终接受的所有不等式用整数、有理数及带方向的平方根包络核验。

## 2. 量词与参考定义

令 d=1536。W8 表中 token v 的精确 affine 反量化行为 $e_v$，初始隐藏表示为 $h_0(v)=\sqrt d\,e_v$。当前实现的第一个 attention 残差输出为

$$
H_p(v)=\sqrt d\,e_v+a_p(v),
$$

其中 $a_p(v)$ 是 attention 分支经过 `post_attention_layernorm` 的结果。前缀 p、位置和历史缓存可以任意变化，以下证明不依赖其具体值，只要求该参考 RMSNorm 的输入有限。

这还没有经过 FFN、PLE 或层末 scalar。PLE 在当前计算图中并不直接改变本处的 h0，但后续完整证明必须纳入它。

“W8 参数”在此指量化权重的码与元数据定义的固定系数。真实 embedding BF16 反量化、初始缩放、RMSNorm 等算子的执行舍入尚未计入，因此不得将本结果描述为实际 W8/KV8 端到端认证。

## 3. 为什么只用最大 norm 会失败，而方向约束可以证明一部分

设 attention 的 post RMSNorm 有效缩放向量为 gamma。其输出满足

$$
a_p(v)=\sqrt d\,\operatorname{diag}(\gamma)u_p(v),
\qquad\|u_p(v)\|_2\le1.
$$

这是一个椭球约束，不只是一个半径为 $\sqrt d\|\gamma\|_\infty$ 的大球。某些通道的 gamma 很大，不代表每个方向都能受到同样大的改变。

对任意固定方向 w，由 Cauchy–Schwarz：

$$
|w^Ta_p(v)|\le\sqrt d\|\gamma\odot w\|_2.
$$

因此对同一前缀下的候选 u、v，令 $\Delta e=e_u-e_v$，有

$$
w^T(H_p(u)-H_p(v))
\ge\sqrt d\left(w^T\Delta e-2\|\gamma\odot w\|_2\right).
$$

再用 $w^Tz\le\|w\|_2\|z\|_2$，得到完整证书：

$$
\boxed{
\|H_p(u)-H_p(v)\|_2\ge
\frac{\sqrt d}{\|w\|_2}
\max\{0,w^T\Delta e-2\|\gamma\odot w\|_2\}.
}
$$

这个不等式对所有前缀成立。它保留输入差异的方向及实际 gamma 的逐维结构，而不要求知道具体 attention 输出。

方向选择是寻找证书，不承担证明正确性。实现先用 $w_j\propto\Delta e_j/\gamma_j^2$ 寻找有用方向，再取一个固定二进制有理方向逐项认证；没有假设该方向一定最优。出现零 gamma 时采用安全的提议规则，最终仍使用同一个有声不等式决定是否通过。

本次 gamma 各维非零，还可以把条件写得更直观。令 $D=\operatorname{diag}(|\gamma|)$。由椭球表示，

$$
\|D^{-1}(H_p(u)-H_p(v))\|_2
\ge\sqrt d\left(\|D^{-1}\Delta e\|_2-2\right).
$$

因此，**表行与参数满足 $\|D^{-1}(e_u-e_v)\|_2>2$，就足以保证这个残差位置的两种表示不会重合**。这不是主 embedding 普通距离大于 2；每个通道都按模型自身的 gamma 加权。

实际 45 对数字的加权距离，认证后的统一下界约为 **2.222468020437646，大于 2**。该判断同样使用精确有理数下界，不依赖显示近似。它给出“embedding 表满足什么、模型参数满足什么”的一个真正通过的局部实例；表中更强的普通 L2 下界来自上述固定方向证书。

|---|---:|
| 不同数字对数量 | 45 |
| 第一 attention 残差后得到严格正证书 | 45 |

这些是隐藏表示距离的下界，不是 token 误判概率，也不是允许的 LSB 数值。不能直接拿逐维 RMS 约 0.9 与它们比较。

$$
\frac{128802233218722502047405358863374924876778033199}
{121791803110908424267401608594127193307728576512}>0.
$$

显示值只用于阅读，决定正性使用精确算术。

## 5. 为什么尚不能继续得到深层 KV 保证

如果对 FFN 也只保留其 post RMSNorm 椭球，便得到

$$
H^{AF}_p(v)=\sqrt d\,e_v+a_p(v)+f_p(v),
$$

其中 a、f 各自受一个归一化椭球约束，但两者之间的真实计算依赖被放松。

这次不只是“某个所选方向没有找到正下界”：对 45 对数字，我们都构造并核验了该放松集合中的抵消分解。设 attention/FFN 两个 gamma 的绝对值为 g、r，逐坐标定义

$$
z_{A,j}=\frac{\Delta e_j g_j}{2(g_j^2+r_j^2)},
\qquad
z_{F,j}=\frac{\Delta e_j r_j}{2(g_j^2+r_j^2)}.
$$

当分母为零且分子为零时取 0；本次参数检查满足所需条件。代数上严格有

$$
\Delta e=2\operatorname{diag}(g)z_A+2\operatorname{diag}(r)z_F.
$$

全部数字对还满足 $\|z_A\|_2\le1$、$\|z_F\|_2\le1$，已用有理数上界认证。取两种候选的抽象分支输出为相反的这些向量，即可在该放松模型里完全抵消 embedding 差异。

**这不是实际 Gemma 碰撞或可达前缀反例。** 这些分支输出未必能由同一前缀、真实 attention、FFN 权重及中间隐藏状态同时产生。它证明的是：只用两组归一化范围、不保留 FFN 与输入之间的关系，这种方法无法给出正分离界；仅优化证书方向也救不了它。

后续若继续使用同类独立范围抽象，无法由此得到第 10、15 层的正 KV 下界。但真实 FFN 可能保持差异，后续 PLE 也可能重新引入 token 差异，都需要在实际计算关系中另证。

## 6. 要完成原问题，还必须补的部分

后续已将真实 FFN 依赖纳入，得到一个具体障碍：[FFN 证明尝试](../gemma_ffn_proof_attempt/README.md)。该参考 FFN 残差映射在连续全空间上非单射，原范围椭球内也不存在统一正距离缩放下界。这没有给出合法 token／同一前缀的碰撞；说明后续需要保留有限码本与可达状态关系。

1. 将实际 FFN 权重、GELU 门控与中间隐藏的依赖纳入成对验证，不能把 FFN 输出当成椭球内的任意点。
2. 在后续层继续保留同一前缀、attention 的共同历史与实际 PLE 输入对应关系。
3. 在目标层认证有限候选经 K/V 投影与 head norm 后仍保持正间隔。
4. 引入真正的 BF16、KV8 与执行路径误差模型；不能把最大单维 ±4 LSB 当作各维独立噪声，也不能把未定义单位的 0.9 当成全域 L2 上界。

所以，本轮完成了一个真实参数驱动、全前缀有效的**局部数学保证**，并定位出范围法在 FFN 处的不足；原先要求的深层 KV/INT8 稳健恢复证明仍未完成。
